How to use these

Every guide opens with a How to Read This Book chapter that says which parts matter most and which you can skip on a first pass — start there rather than at chapter one. Each also ends with a cheat-sheet appendix worth keeping open in a tab while you work.

Press Ctrl + K inside any guide to search every heading in it. Tick the checkboxes in the sidebar to track what you have read — that progress is saved in your browser, per guide.
